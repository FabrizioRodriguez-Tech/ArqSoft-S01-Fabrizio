#  VALORANT - CATALOGO DE AGENTES

La aplicación permite el reclutamiento, visualización y análisis de capacidades de agentes especializados.

##  Descripción
El sistema funciona como un **Catalogo de Agentes** donde se pueden registrar nuevos agentes, visualizar sus estadísticas de combate (Daño, Movilidad, Utilidad, etc.) mediante gráficos de radar y experimentar una cinemática de despliegue al confirmar un nuevo ingreso.

### Características Principales:
*   **Gestión de Agentes**: Registro completo con validación de datos operativos.
*   **Visualización Táctica**: Gráficos de radar dinámicos (Pentágonos de Stats) integrados con Chart.js.
*   **UI Adaptativa**: Sistema de siluetas de emergencia y escaneo láser por CSS cuando no hay archivos de imagen disponibles.
*   **Motor de Cinemáticas**: Integración de video nativo para confirmación de reclutamiento exitoso.

## Tecnologías Usadas
*   **Backend**: .NET 8 / ASP.NET Core MVC.
*   **Frontend**: Razor Pages, HTML5, CSS3 Moderno (Variables, Flexbox, Clip-paths).
*   **Diseño**: Estética de interfaz de usuario (UI) basada en el universo de Valorant.
*   **Librerías Externas**: 
    *   **Chart.js**: Para la renderización de análisis de rendimiento.
    *   **Bootstrap 5**: Para la estructura responsiva base.
